# Единый магазин StroySnab — 12 ноября 2026

По просьбе владельца витрина переведена с модели маркетплейса на собственный онлайн-магазин.

- Удалены страницы /seller, API /api/seller, страница и API приглашений, управление владельцами и приглашениями из админки.
- Старые роли поставщиков лишены разрешений; вход по паролю и коду закрыт, ранее выданные сессии отвергаются. Миграция 0023 блокирует старые аккаунты поставщиков и удаляет их сессии. Записи поставщиков, закупочные предложения и история заказов сохранены.
- На витрине одно предложение StroySnab: выбирается доступное предложение по действующим правилам цены и остатка. Нельзя показывать суммарный остаток всех поставщиков как доступный остаток одного предложения.
- Количество магазинов, выбор магазина, имена и телефоны поставщиков исключены из публичного товара и покупательского заказа. JSON-LD описывает одно предложение продавца StroySnab.
- Старые тестовые подписи Памир, Вахш, Душанбе Материал, Сомон Строй и названия источников закупки убраны из публичных текстов, подсказок поиска, корзины, оформления и документов. Исходные данные хранятся в админке; реальные бренды производителей сохраняются.
- В админском каталоге есть колонка поставщиков со ссылкой на закупочные предложения. Показываются как источники предложений, так и первоначальный поставщик товара. В заказе остаются поставщики и закупочные суммы; самостоятельной готовности магазинов больше нет.
- Новые заказы формируют очередь уведомлений для активных SUPER_ADMIN / ADMIN / SALES_MANAGER, а не поставщиков. Старые неотправленные уведомления магазинам отменяются миграцией; диспетчер также исключает такую аудиторию. Реальная SMS-отправка по-прежнему требует одобренных шаблонов и подключения диспетчера.

Проверка: полный набор 49 файлов / 207 тестов прошёл до уточнения публичных названий. После уточнения прошли 25 тестов затронутых сценариев, включая новые проверки очистки названий. Проверка production UI: старые маршруты 404, магазинный вход 401, покупка без выбора поставщика, получение нового заказа в админке, сохранение источников товаров и отсутствие управления магазинными аккаунтами. Все тестовые заказы создавались локально. Миграция проверена на локальной базе с ранее созданными магазинными аккаунтами.

Дополнение: подбор КП сравнивает нормализованные публичные названия, сохраняя исходное название кандидата и поставщика для менеджера. Проверка exact-match прошла. Живая витрина www.stroysnab.tj проверена после развёртывания: нет тестовых названий поставщиков и их количества, страницы кабинета магазина возвращают 404.
