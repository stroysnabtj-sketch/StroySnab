# Продолжение: второй фактор и подготовка автоматизации КП

Пользователь разрешил продолжать правки. ИИ: только подготовка без подключения.

1. Реализовать TOTP (RFC 6238) с тестовыми векторами, шифрованием секрета AES-GCM и хешированными одноразовыми резервными кодами.
2. Добавить схему и миграцию; настройка требует пароля, подтверждение — первого кода. Вход не создаёт сеанс до проверки второго фактора. Проверки сериализуются по пользователю, повтор кода запрещён. Ограничить попытки.
3. Единая страница безопасности для покупателя, магазина и сотрудника, ссылка из кабинетов; двухшаговая форма входа без выбора роли.
4. Подготовить интерфейс провайдера разбора документов, локальный безопасный поиск кандидатов и ручной черновик КП. Без внешних сетевых вызовов и автоотправки.
5. Проверить unit/integration, типы, линтер, реальный вход/настройку и существующую цепочку КП. Документировать ограничения, ключ шифрования и оставшуюся работу.

Первый запуск 2FA добровольный: обязательность для персонала включать после подключения и процесса восстановления, чтобы не заблокировать существующие рабочие аккаунты. Сброс пароля не отключает второй фактор.
