# Реферальные приглашения

Одобренный владельцем вариант: по исходному ТЗ, приглашения и статистика без начисления бонусов. Next.js/Node/PostgreSQL сохраняются.

Постоянный уникальный код из 8 hex-символов создаётся лениво. /r/CODE перенаправляет на регистрацию и сохраняет корректный по формату код в HttpOnly SameSite=Lax cookie на 30 дней. Известность кода не раскрывается маршрутом. Зарегистрированным пользователям предлагается собственная страница приглашений.

В обоих способах регистрации связь создаётся атомарно вместе с клиентом и одной записью PENDING. Неверные, неизвестные и неактивные/удалённые пригласившие игнорируются; регистрация остаётся обычной. Самоприглашение и повторная привязка исключены. При непредвиденном сбое БД транзакция откатывается целиком: не скрываем потерю согласованной связи.

Кабинет показывает ссылку, копирование/поделиться, приглашённых, ожидающих и число начисленных бонусов (пока ноль). Нет списка чужих персональных данных, обещаний суммы, выплат, скидок и управления балансом. API доступен только покупателю; ссылка строится из настройки сайта, не Host.

Уникальность кода и приглашённого, внешние ключи и CHECK запрещают дубли/самоссылку. Генерация CAS с пятью попытками; аудит создания кода и связи. Страница и API без общего кэша. RU/TG интерфейс, адаптивность, клавиатура и контраст.
