# Жёлтая палитра и фотографии

Дата: 03.11.2026. Основание: приложенный пользователем снимок интерфейса RateHawk; пользователь разрешил сменить палитру и сгенерировать пару фотографий для сайта.

Основные цвета: насыщенный жёлтый `#FFE000`, жёлтый кнопок `#FFE149`, графит `#30343B`, светло-серый фон `#F4F4F5`, белые карточки. Палитра применена к главной, общим кнопкам/навигации, каталогу и рабочим панелям. Активный пункт бокового меню теперь определяется текущим URL. Цветовые статусы наличия/ошибок остаются смысловыми состояниями интерфейса.

Созданы два изображения через встроенный imagegen и сохранены в проект:

- `public/images/editorial/materials-yellow-v1.webp` — строительные материалы; первый экран главной. 1536×1024, около 377 КБ.
- `public/images/editorial/workshop-yellow-v1.webp` — замер доски с жёлтой рулеткой; блок заявки. 1000 px по ширине, около 128 КБ.

Это сгенерированная редакционная графика для оформления, а не фотографии конкретных продаваемых SKU или подтверждённого склада магазина. Изображения не привязаны к карточкам товаров как свидетельство их внешнего вида. Оригинальные PNG сохранены генератором; сайт использует оптимизированные WebP и Next Image с адаптивной загрузкой.

Главная проверена в браузере при 1440, 390 и 360 px: оба изображения загружены; ширина документа совпадает с viewport, ошибок JavaScript не зафиксировано. Выполнены TypeScript и ESLint. Снимки и наблюдения находятся рядом с этим документом; финальные снимки обновляются на production-сборке.

Финальная production-сборка `npm run build:noenv` прошла. На ней повторно проверены обе фотографии, отсутствие переполнения на трёх ширинах и активный жёлтый пункт меню админки; все 6 браузерных сценариев каталога прошли. Финальные PNG в этой папке сняты с production-предпросмотра.
